Установка

Три шага от пустого каталога до первого запроса к агенту.

1

Клонируйте репозиторий

# клонирование
$ git clone https://github.com/ilyshaxoroshi/openok.git
$ cd openok
2

Поставьте зависимости

$ bun install
3

Запустите

# терминальная версия
$ bun run dev

# десктоп-приложение
$ bun run dev:desktop
